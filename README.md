# 🚌 BusCompare India — Full-Stack Bus Price Comparison SaaS

**BusCompare India** is a full-stack web application that allows users to compare bus ticket prices across major Indian ticketing platforms like **RedBus**, **AbhiBus**, **MakeMyTrip**, and **Yatra**, finding the cheapest tickets for any route.

---

## ✨ Features

- 🚌 **Multi-Platform Price Comparison**: Compare ticket fares across RedBus, AbhiBus, MakeMyTrip, Yatra & Direct operator booking.
- ⚡ **WhatsApp & Email Price Alerts**: Subscribe to route price drops with target price thresholds.
- 🔍 **Advanced Filtering**: Filter by bus type (AC Sleeper, Luxury, Non-AC), departure time, operator, amenities, and price.
- ⭐ **Verified Passenger Reviews**: Real passenger review system with running rating calculation.
- 📊 **Founder Admin Dashboard**: Real-time analytics, revenue tracking (@ ₹80 avg affiliate commission/click), platform click distribution, top routes, and subscriber list (Password protected: `001200`).
- 📡 **REST API & SEO**: Express backend serving dynamic routes, search API, affiliate tracking, and `/sitemap.xml`.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Channu0012/buspricecomparer.git
   cd buspricecomparer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the server:**
   ```bash
   npm start
   ```

## 💼 Revenue Model

- **Affiliate Commissions**: Earns ₹50 – ₹150 per successful bus booking via affiliate redirect links (`/go/:platform/:busId`).
- **Pro Alert Subscriptions**: Monetizes price drop alerts at ₹99/month for unlimited WhatsApp alerts.
- **Display Ads (AdSense)**: High intent travel search traffic monetization.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla Glassmorphism Design System), JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Database**: Flat-file JSON database (`database.json`) with low-latency reads/writes
- **Icons & Typography**: Google Fonts (Inter & Outfit), SVG Icons
